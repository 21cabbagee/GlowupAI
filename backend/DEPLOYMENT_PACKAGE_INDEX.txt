═══════════════════════════════════════════════════════════════════════════
  DEPLOYMENT STEPS (COPY-PASTE)
═══════════════════════════════════════════════════════════════════════════

1. Install Railway CLI:
   npm install -g @railway/cli && railway login

2. Initialize Project:
   cd /Users/21cabbage/Skinproof/backend && railway init

3. Add PostgreSQL:
   Railway Dashboard → New → Database → PostgreSQL

4. Generate Secrets:
   source railway-commands.sh && generate_all_secrets

5. Set Variables:
   Copy from .env.production.template → Railway Dashboard

6. Create Volume:
   Settings → Volumes → New Volume (photos, /data/photos)

7. Deploy:
   railway up

8. Verify:
   check_health
