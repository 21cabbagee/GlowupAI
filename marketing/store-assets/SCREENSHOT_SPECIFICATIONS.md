# Google Play Store Screenshot Specifications

## Technical Requirements

### Screenshot Dimensions
- **Required size:** 1080 x 2340 pixels (16:9 aspect ratio)
- **Format:** PNG or JPEG
- **Number required:** Minimum 2, maximum 8 (we'll use 8 for maximum impact)
- **File size:** Under 8MB each

### Feature Graphic
- **Size:** 1024 x 500 pixels
- **Format:** PNG or JPEG
- **Usage:** Displayed at top of store listing

### Promo Video (Optional)
- **Length:** 30 seconds - 2 minutes
- **Format:** YouTube link
- **Recommended:** 30-60 seconds showing key features

## Design Guidelines for All Screenshots

### Visual Consistency
- Use the "Honey" design system throughout (warm amber/orange gradient #FFB84D to #FF8C42)
- Consistent UI elements (buttons, cards, typography)
- Material 3 design language
- Clean, modern, minimalist aesthetic

### Realism
- Show achievable results (not overnight transformations)
- Use realistic streak numbers (7-30 days, not 365)
- Show realistic metrics (improvement, not perfection)
- Include some neutral/negative data (builds trust)

### Diversity & Inclusion
- Use diverse skin tones across screenshots (if showing faces)
- Vary gender representation
- Avoid beauty standards bias
- Focus on progress, not "perfect" skin

### Privacy
- Never show real user photos without consent
- Anonymize any personal data
- Use generic names if showing user profiles
- Consider illustrated/stylized representations for faces

### Accessibility
- High contrast for text overlays
- Large, readable fonts
- Color indicators + text labels (not color alone)
- WCAG AA contrast ratios

### Annotations & Text Overlays

**If using text overlays:**
- Keep text short (5-7 words max)
- Use white or dark text with subtle shadow for readability
- Position at top or bottom third of image
- Use brand font (SF Pro, Roboto, or similar)
- Don't obscure important UI elements

**Alternatively:** Let the UI speak for itself (no overlays)
- Google Play now auto-generates captions
- Clean screenshots often convert better
- Consider A/B testing with and without text

## A/B Testing Opportunities

Once launched, test:

1. **Screenshot order** - Which screenshot converts best as #1?
2. **Text overlays** - With vs without captions
3. **UI style** - Light mode vs dark mode screenshots
4. **Feature emphasis** - Which features resonate most?
5. **Face visibility** - Showing faces vs UI-only

Use Google Play Console's **Store Listing Experiments** feature (free).
